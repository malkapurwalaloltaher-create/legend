✨ Features

  • Red terminal UI with sound effects
  • Gothic, dot-pixel, block, fullwidth, bubble, square, small caps, spaced, and random styles
  • Discord-style copy combo up to Legendary Copied
  • No backend, no Python, no build step

🚀 Setup

  1. Upload all files to your GitHub repo.
  2. Open Settings → Pages.
  3. Select your branch and root folder.
  4. Save and open your GitHub Pages link.
