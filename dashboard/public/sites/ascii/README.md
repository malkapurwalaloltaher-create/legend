# ASCII Generator 🔴 ⚡

Official website: **https://legend.maqraat.com**

Made by **Xavier / Mr Xavier** as part of the Legendary Labs project collection.

## ✨ What is this?
A static JavaScript ASCII and styled-text generator with red terminal UI, sound effects, gothic text, dot-pixel letters, block style, fullwidth, bubble, square, small caps, and copy combo feedback.

## 🚀 GitHub Pages Setup
1. Upload all files to your GitHub repository.
2. Go to **Settings → Pages**.
3. Choose the branch and root folder.
4. Open your GitHub Pages link after deployment.
5. Type text, choose a style, press Generate, then copy or save the output.
